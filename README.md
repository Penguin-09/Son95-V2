# son95-v2

Son95 V2 is a revamp of Son95, a recreation of the classic Windows 95 experience, reimagined as a personal portfolio. With Son95, you can discover information about me, my projects, and more.

## Quick Start Guide

### 1. Requirements

- Node.js 22.12.0 or higher
- npm 10.9.0 or higher

### 2. Installation

Run `npm install` to install the dependencies

### 3. Running the Development Server

Run `npm run dev` to start the development server

## Formatting

Run `npm run format` to format the code based on the `.prettierrc` file

## Building

Run `npm run build` to build the project for production
